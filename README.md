# ЖК Мега — приём заявок от жителей

Веб-приложение (PWA) для жилого комплекса «Мега»:

- **`index.html`** — жители: регистрация/вход по телефону и паролю, подача заявки, «Мои заявки», профиль.
- **`admin.html`** — администратор: реестр заявок, импорт из WhatsApp, сводка, аналитика, список жителей.

Хранение и авторизация — Firebase (Auth Email/Password + Firestore). Без настроек в `firebase-config.js`
сайт работает в упрощённом режиме: заявки отправляются в WhatsApp, реестр хранится на устройстве администратора.

Установка и настройка — см. [КАК УСТАНОВИТЬ.txt](КАК%20УСТАНОВИТЬ.txt). Правила доступа — [`firestore.rules`](firestore.rules).
