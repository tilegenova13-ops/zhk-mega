ЖК Мега — установка
===================

Части сайта:
  index.html          — для ЖИТЕЛЕЙ: вход/регистрация, подача заявки, «Мои заявки», профиль.
  admin.html          — для АДМИНИСТРАТОРА: вход, реестр, импорт WhatsApp, аналитика, список жителей.
  firebase-config.js  — сюда вставляются настройки Firebase (шаг 1).
  firestore.rules     — правила доступа к базе (шаг 1.5).
  zhk-firebase.js, sw.js, манифесты, icons — служебные файлы, не трогать.

Пока firebase-config.js не заполнен, сайт работает по-старому: без входа,
заявки уходят в WhatsApp на номер 77476202646, реестр админа хранится только
на его устройстве.


1. ПОДКЛЮЧИТЬ FIREBASE (бесплатно, один раз)
   1.1 Откройте https://console.firebase.google.com и войдите своим Google-аккаунтом.
   1.2 «Create a project» (Создать проект) → имя, например zhk-mega → Google Analytics можно выключить.
   1.3 Слева Build → Authentication → Get started → вкладка Sign-in method →
       Email/Password → включить (Enable) → Save.
       (Вход по номеру телефона работает через этот способ — SMS не нужны.)
   1.4 Слева Build → Firestore Database → Create database →
       Location: europe-west (или ближайший) → Start in production mode → Create.
   1.5 В Firestore откройте вкладку Rules, удалите всё и вставьте содержимое файла
       firestore.rules целиком → Publish.
   1.6 ⚙ (Project settings) → General → внизу «Your apps» → значок </> (Web) →
       имя любое → Register app. Появится блок const firebaseConfig = { ... }.
   1.7 Откройте firebase-config.js в Блокноте и перенесите значения
       apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId
       в соответствующие кавычки. Сохраните.

2. РАЗМЕСТИТЬ САЙТ
   • Откройте https://app.netlify.com/drop и перетащите туда ВСЮ папку «zhk-mega-app».
   • Зарегистрируйтесь в Netlify, иначе сайт удалится через час.
   • Получите адрес вида https://имя.netlify.app (Site configuration → Change site name).
   • В Firebase: Authentication → Settings → Authorized domains → Add domain →
     впишите ваш адрес без https:// (например zhk-mega.netlify.app).
   • При каждом изменении файлов — снова перетащите папку (Deploys → перетащить в область).

3. СТАТЬ АДМИНИСТРАТОРОМ (один раз)
   3.1 Откройте https://ваш-сайт/admin.html → «Первый вход? Создать аккаунт администратора» →
       номер телефона, имя, пароль.
   3.2 Появится экран «Нет прав администратора» с вашим ID. Нажмите «Скопировать ID».
   3.3 Firebase → Firestore Database → Data → Start collection →
       Collection ID: admins → Next → Document ID: вставьте скопированный ID →
       поле: role, значение: admin → Save.
   3.4 Вернитесь на сайт → «Проверить снова». Готово, вы в панели.
   Второго администратора добавляют так же (ещё один документ в admins).

4. ЖИТЕЛЯМ
   Ссылка: https://ваш-сайт/  — повесьте QR-код в подъездах (QR есть во вкладке «Жителям»).
   Житель один раз регистрируется: имя, квартира, подъезд, телефон, пароль.
   Затем подаёт заявки — они сразу появляются у вас в реестре с пометкой «Приложение».
   Статус и ваши отметки «Ход исполнения» житель видит во вкладке «Мои заявки».
   Установка на телефон: Android/Chrome — «Установить»; iPhone/Safari — «Поделиться» →
   «На экран „Домой“».

5. ЖИТЕЛЬ ЗАБЫЛ ПАРОЛЬ
   Firebase → Authentication → Users → найдите его номер (77…@zhk-mega.app) →
   ⋮ → Delete account. После этого житель регистрируется заново с тем же номером.
   (Старые заявки останутся в вашем реестре, но в его «Моих заявках» не появятся.)
   Сменить пароль самому житель может в «Профиле».

6. ИМПОРТ ИЗ WHATSAPP (как раньше)
   WhatsApp → чат → ⋮ → Ещё → Экспорт чата → Без медиафайлов.
   В панели: вкладка «WhatsApp» → загрузите файл. Попадут сообщения с вашим
   упоминанием и заявки из формы «ЗАЯВКА · ЖК Мега».
