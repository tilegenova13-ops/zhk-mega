Импорт заявок из WhatsApp

Как выгрузить чат дома

  1. Откройте групповой чат дома в WhatsApp.
  2. Меню ⋮ (или имя группы на iPhone) → Ещё → Экспорт чата → Без медиафайлов.
  3. Сохраните файл .txt (на iPhone — распакуйте .zip) и перетащите его сюда, либо скопируйте сообщения и вставьте текстом.
  4. Приложение отберёт сообщения, где вас упомянули, и заявки из формы жителей («ЗАЯВКА · ЖК Мега») и предложит добавить их в реестр. Повторы отсекаются автоматически.
  5. Одну заявку из личного чата можно просто скопировать из WhatsApp и вставить в поле справа.
Имя или номер после «@», как они выглядят в чате. Можно добавить слова-обращения, например «председатель» или «КСК».

Портал для жителей

Как жители подают заявки

  1. Житель открывает страницу «Подать заявку» по ссылке или QR-коду на двери подъезда.
  2. Регистрируется по номеру телефона и паролю (имя, квартира, подъезд) — один раз.
  3. Подаёт заявку — она сразу появляется у вас в реестре с пометкой «Приложение».
  4. Житель видит статус и ваши отметки «Ход исполнения» во вкладке «Мои заявки».
  5. Сообщения из чата WhatsApp по-прежнему можно импортировать во вкладке «WhatsApp».

Жители видят только свои заявки. Реестр, аналитика и настройки доступны только администраторам.

Зарегистрированные жители

Если житель забыл пароль: Firebase Console → Authentication → Users → найдите его номер (…@zhk-mega.app) → ⋮ → Delete account. После этого он сможет зарегистрироваться заново с тем же номером.

Так страницу видят жители.
